# Metrology Workspace v4.2.0

Windows x64 release of the cumulative changes since v4.1.1.

## Changes

- Wafer Map and Radius Plot now use static PyQtGraph screen rendering. Existing
  interpolation, signed radius, color scaling, contours, edge fill, point-value
  precision and measurement strings are retained. Plot-internal navigation and
  selection are disabled; window resizing, scrolling, whole-page Ctrl+wheel
  magnification and Fit width remain available. Copy PNG and other exports
  retain the Matplotlib renderer rather than capturing a lower-resolution screen.
- Floating editors have a native top-left pin icon (Alt+P). Unpinned panels stay
  above their parent; pinned panels stay above this application's windows only,
  never above another application. Activating a float does not raise its Workbook
  over sibling analysis windows. The redundant floating-window instruction row
  is removed.
- Analysis-window close no longer waits for an in-flight numerical worker.
  Workers finish safely without late rendering. Recovery candidates batch SQLite
  writes and share equal frame payloads, while retaining validation, final fsync,
  atomic replacement, revision checks and independently editable recovered data.
- Correlation and Match Y axes show the actual values without automatic SI
  multipliers. RAW–RAW correlations are blue, REF–REF orange and REF–RAW green;
  added Trend axes include their own Raw/Reference identity.
- Native Excel and Matplotlib exports use horizontal prepared Match tables from
  A1 and charts over the data from A5, including Original, Group and Wafer views.
  There is no duplicate visible Reference block or synthetic Fit-endpoint table.
  Native Match uses an actual editable Excel linear trendline with equation/R²;
  Excel refits edited worksheet inputs independently of the software's Card.
- Trend/Bias retain every observation, tight X limits, and WKB Wafer/Group footer
  hierarchy. Width adapts to visible tick and caption demand instead of being
  fixed. Tick marks match the label interval. Titles/equations are centered;
  Match has 5 pt markers and Trend/Bias have 4 pt markers with 1.8 pt strokes.
  Matplotlib uses the corresponding thicker styles and its own renderer.
- FM prepared Wafer/Die Seq/parameter data starts at A1, with literal source data
  to the right. Visuals start at A5 in FM Trend / Wafer Map / Radius order (NOVA
  and KLA omit TEM-only FM Trends). Complete Copy PNG grids remain intact and
  proportional: each Wafer Map grid row is 8 cm high; Radius retains the enlarged
  30 cm-height / 72 cm-width limits. Maps are not cropped into individual exports.
- Dynamic keeps editable source data, formula-linked pivots and 3 Sigma charts;
  parameter charts are stacked on the left, summary table/chart aligned at the
  upper right. Charts are 18 cm wide. Per-Die Cycle Trends remain in the software,
  but their duplicate curves and helper tables are not exported.
- Export preparation paints progress before snapshot capture, then offers actual
  output-sheet checkboxes. All sheets are selected by default. Cancel/empty
  selection writes nothing; selected outputs keep required formula/chart sources
  hidden and editable, without hidden-source charts. Closing the owner cancels
  an open chooser safely. Programmatic exports still default to all sheets.
- Open Recent WKB retains 20 entries. With either Head or Mark enabled, grouped
  Trend order offers Group and Original row order, not redundant Wafer order.

The preliminary full run executed 1,017 tests in 819.460 s with three failures:
an obsolete FM test read the new A1 formula report as cached literal values,
Raw clear/undo took 0.6070745 s against <0.6 s, and grouped Correlation restore
took 2.1089435 s against <2.0 s. The FM source table and every prepared formula
were verified intact; that test now checks both explicitly rather than asking
pandas to calculate formulas. Its 17-test related run passed in 9.960 s.
No production export calculation, performance threshold or test population was
changed for this release correction. The fresh complete run is reported above.

Scientific calculations and data are not simplified for rendering speed. RBF
interpolation, first-use initialization and very large exports can still take
time. The prior UC point/line screenshot's original cause was not established;
checks found matching line/marker data and did not alter measurements to mask it.
Prepared reports contain live formulas. Excel recalculates them on opening;
readers such as pandas/openpyxl do not evaluate those formulas and can see empty
cached results before recalculation. The literal source values remain present.
The installer is unsigned; Windows may show an unknown-publisher warning.
