# Metrology Workspace v5.5.0

Windows 10/11 x64 可下载发布页上的 `MetrologyWorkspace-v5.5.0-Windows-x64-Setup.exe`。发布页提供 SHA-256 校验文件。

- Correlation and Trend 新增 Wafer Mean / Sigma，显示等宽的 Mean、Sigma 和 Bias 图。Analysis 菜单分别控制 Trend 和 Mean/Sigma 的 Y 轴，默认显示三位小数。Compare 配色避开主系列颜色，Combined Group 在原有分组下单独显示。
- Wafer Map、Radius、Correlation、Trend 和 Spectrum Die Map 支持框选、移除、取消勾选与恢复。Ctrl 加左键框选缩放。TestFlag 可通过图表或 Group settings 设置，默认值为 0。
- Match Workbook 的 Group settings 按 Raw Data 行顺序显示测点。Data Selection 的筛选窗口用 Available Values 和 Filter Pool 管理筛选范围。
- Reference Summarizer 可把多个 Ref 输出以及各自的 Raw Data 和 wafer 配对保存到同一个 `.ref` 文件。
- Spectra Viewer 的 Auto 导入压缩使用本机允许的最大偶数线程数。导入保留文件顺序和嵌入内容，Paths Only 跳过嵌入准备。
