# v4.1.0 — Reversible data views and live plot comparison

Date: 2026-10-21. Tag: `v4.1.0`. Application `VERSION`: `4.1.0`.

## Changes since v4.0.1

- Groups → Data selection adds **Hide excluded rows in tables**. Apply hides
  unchecked records from Order, Reference and Raw Data without deleting source
  cells or changing analysis participation. Uncheck and Apply restores them.
  Original source row numbers, exclusions and editable strings are retained.
- Projected Ctrl+V edits only the corresponding visible source rows, including
  non-contiguous records. Partial pastes are allowed; overflowing the remaining
  visible rows is rejected before writing. Whole-table replacement cannot bypass
  hidden-row protection. Undo remains source-aligned.
- Wafer Map / Radius and Correlation / Trend editors retain their full documents.
  Match Workbook selection follows the Workbook's hide preference; Full data
  restores full visibility. Plot participation is independent of visibility.
  Completely excluded Wafers do not create empty Map boxes, and unchanged-source
  Map/Radius caches now include exact participating row membership.
- Group boundaries remain thick black dashed lines. Wafer boundaries are thin
  grey dashed lines behind the measurements, in Workbook and child Trend plots
  and their render mirrors.
- Trend/Bias summaries are automatic empty-space tooltips: Mean, sample sigma
  (n−1), Min and Max over all finite selected observations. Point tooltips show
  Die and literal plotted X/Y instead, and restore the summary on leaving the
  point. No statistics checkbox or title annotation is required. This also
  applies to the child and Dynamic Trend workspaces.
- Group plots offers mutually exclusive **All-parameter Card** and **Group Card**
  Trend calibration. The first uses the All parameter plots fit; the second uses
  the displayed Group's own fit. Coefficients are not applied twice.
- Double-click Raw Data outside its table to detach the same live editor into
  a non-modal, topmost tool window. Double-click again or close that tool window
  to dock it. Its model, Ctrl+C / Ctrl+V, Undo/Redo and plot update connections
  remain intact; detachment does not create a data copy or close the document.
- Wafer Map **Decimals** follows Opacity and defaults to 2 (range 0–10). Decimal
  ties round half up, including negatives. This is a shared application Settings
  preference, not a Workbook preference; legacy document controls cannot override
  it. Source precision, interpolation, color scaling and statistics do not change.
  Screen, copied PNG and report export all use the current point-label precision.
- Preview/Final first population or temporary clearing no longer drops persisted
  data-selection IDs. Source identity/order guards remain in place.
- Dynamic Trend adds one-panel-per-parameter all-Die comparison and same-Die
  multi-parameter Add Compare. The ineffective Restore control is removed.
  Trend Y axes keep literal values instead of hiding an SI multiplier in labels.
- New Match documents use `.mwkb`; legacy `.wkb` and `.bak` files remain readable.
  Opening a backup does not permit overwriting that backup as a formal document.
- Carries forward the focused startup, exact-snapshot, source-ID, sheet bulk-load
  and dirty-check changes from the intervening local work. No performance
  improvement is claimed without its recorded representative measurement.
- Further interaction preparation batches native selector notifications, retains
  exact selections and unchanged headers, and shares Trend identity/tick text.
  Three fresh-process probes per side on the same 6,000-row fixture measured
  median checkbox latency **142.003 → 109.934 ms (22.6% less)** and complete
  grouped-Correlation restoration **1686.059 → 1523.633 ms (9.6% less)**.
  First large-Workbook opening remained about 3.5 s; no further startup
  improvement is claimed. Full curves, columns, fits and literal rows remain
  intact. See `docs/plans/interaction-performance-2026-10-21.md` for samples,
  rejected experiment, reproducibility boundaries and regression checks.
