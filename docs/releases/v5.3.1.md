# v5.3.1 — Group scripts and Spectra interactions

Source tag: `v5.3.1`, based on `v5.3.0`. Published as a source tag on
2026-11-15; this tag does not include a new Windows installer.

- Group Script supports readable copy/paste, validation and application in
  Workbook and Spectra Group settings, alongside the existing Data Selection
  script workflow.
- Spectra Tree and Die Map context menus expose the combined selection,
  TestFlag, Group, Mark and Highlight actions, using the same document history.
- Selected Die Map points accept typed TestFlag numbers only from the
  configured flag definitions, including multi-digit and negative values.
- Spectra Color By adds Folder and TestFlag, with category legends, floating
  plot synchronization, Undo/Redo updates and document persistence.
- Wafer Map and Radius apply independent PAD/Lot caption switches consistently
  on screen and in exports, preserving literal Group and Wafer names.
- Wafer window initialization reuses the existing input transaction and dense
  table storage. The 6,000-row opening regression measured 0.202–0.367 seconds
  versus 0.804 seconds before the fix; the original 0.4-second limit remains.
