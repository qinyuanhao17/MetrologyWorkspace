# Metrology Workspace v4.3.0

Source-only release containing the cumulative changes since v4.2.0. This tag
does not publish `main`, create a new branch, or provide new Windows binaries.

## Changes

- Large uniform tables now use a bounded native selection path while preserving
  the actual selection model, `selectionChanged` notifications, disabled-cell
  fallbacks, sorting, filtering, hidden rows and single-step Undo/Redo. In the
  Windows 100k x 33 regression, cold Ctrl+A fell from 6698.23 ms to 21.47 ms
  P50, and Shift selection from about 7.2 s to 15-21 ms. These figures do not
  include a completed analysis or plot refresh.
- Workbook input presence checks use a guarded Pandas-native fast path for
  literal strings, with exact fallback for mixed and typed values. The fast
  path preserves whitespace, high-precision source strings, missing values,
  string subclasses and original row/column ownership.
- Wafer Map and Radius Plot hover again reports the Die and value, together
  with X/Y or signed-radius context. Map and Radius exports use a common row
  height, and Trend/Bias curves use the same 2.5 pt lines and 6 pt markers in
  the application, native Excel and Matplotlib.
- Bias-limit exports draw the requested red dashed limits in native Excel and
  Matplotlib. Dynamic parameter charts use
  `<N> Cycles Dynamic of <parameter> (nm)`. The unreadable All Dies mode and
  the redundant Single Die selector are intentionally removed; each parameter
  panel remains switchable by Die and can add comparison parameters.
- `Match Group` now contains Group captions only. Groups with Show Wafer are
  exported to the separate `Match Group show Wafer` sheet, retaining every
  visible Wafer/LOT/PAD label and complete separator. Native identity charts
  use a cell-bound numeric x axis shared by cells, captions and dividers,
  avoiding Excel's equal-width category spacing for unequal Groups.
- Match reports place the square Match panel on the left and stack Trend, Bias
  and Bias % vertically to the right. Panel widths follow physical label demand,
  caption leaders are removed, marker headroom is retained, and paginated
  Wafer reports no longer fail when Bias % is enabled.
- Recovery snapshots keep frozen GUI-thread ownership before background
  serialization. Save/Discard cancellation, atomic replacement, revision
  checks, concurrent draft isolation and old-WKB compatibility remain covered.
- Independent wafer interpolation now runs in a bounded thread pool without
  changing RBF inputs, masks, row order, colour limits or scene order. On the
  owned 120-map NOVA scenario, total draw time changed from 4.97 s to 2.82 s
  and surface preparation from 3.48 s to 1.32 s.

## Known limitations

- First selection is substantially faster, but a complete Workbook analysis
  Undo still takes roughly 1.0-1.3 s at 100k x 33. Writer single-cell Undo/Redo,
  wide-table Paste/Delete and multi-window Group/stage switching can still
  suspend the UI for seconds. These paths retain the full analysis, notification,
  ownership and data-integrity semantics.
- Search/filter, full Copy, very large Paste/Delete and long-session resource
  stability were not optimized to the same degree.
- The exception discovered in the original standalone-table benchmark was a
  benchmark window-hierarchy effect. That result is not presented as a
  production initialization speed-up. Real restored NOVA windows still carry
  file loading and first-paint cost.
- No new installer, portable ZIP, signed executable or GitHub binary Release is
  produced by this source tag. v4.2.0 remains the most recent packaged Windows
  release.
