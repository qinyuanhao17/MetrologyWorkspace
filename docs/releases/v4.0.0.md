## Changes

- `Match Original` combines literal raw data, paired Reference values and
  parameter tables/charts. Other Match views reference these exact source
  rows. Preview and Final remain separate; Final is not calibrated twice.
- `Match Original` uses Die ticks in original source order. `Match Group`
  groups Die records and uses the same Trend/Bias panel width. `Match Wafer`
  collects Wafer identities in first-appearance order, preserving source order
  within each identity, with sparse captions and no redundant Wafer axis title.
  Individual group sheet names retain the configured group name.
- Redundant `Original`, `Match`, `Group Fits`, `Order` and `All Trend` sheets
  are removed. Single-wafer metrics include explicit Row numbers, also used
  as the plotted horizontal coordinates.
- Native Excel charts show outward ticks. Group/Wafer names are cell-linked
  chart text boxes, separated from the axis; short groups can fan out with
  leader lines without moving any native data point. Detached short bars do
  not intersect the captions. Dense Die ticks and Wafer captions are sampled;
  all measurement rows remain in their tables.
- Bias and Bias percent use symmetric positive/negative Y limits in both
  renderers. Match retains visible, local editable X/Y ranges and the fixed
  two-point software-fit series, not an Excel regression.
- FullMap contains the successfully drawn software Wafer Map and Radius PNGs
  at a fixed 11 cm display height with aspect ratio preserved, in both export
  modes. TEM also retains mapped Trends; NOVA/KLA do not add FullMap Trends.
- Dynamic exports one aligned sheet: literal raw data on the left, vertically
  stacked Cycle-by-Die tables, corresponding 3 Sigma charts to their right,
  and a combined grouped 3 Sigma chart farther right at the top. Selected Cycle
  trends remain below on the same sheet. Native pivot formulas reuse the
  software's exact selected-set cell mappings and sample standard deviation;
  leading-`=` source labels remain literal text. Matplotlib uses grouped bars
  and the same physical panel size as native Excel.
- Export progress dialogs retain a fixed width. Long progress text is elided
  with the full message available in a tooltip.

No interpolation, regression, calibration, measurement-string precision or
participation rules are changed. Earlier v4 reminder/storage improvements are
included; see [v4-dev3 notes](https://github.com/qinyuanhao17/MetrologyWorkspace/blob/v4-dev3/docs/releases/v4-dev3.md).

## Limits

Native Excel and Matplotlib are not pixel-identical. Native chart captions are
editable Excel drawing shapes; source-range outlines appear when selecting
the measurement series, not merely the outer multi-series chart. Fit values
remain the software result when worksheet ranges are edited.

Wafer Map and Radius use existing successful drawings; export does not trigger
new interpolation. Large workbook loading/rendering can still take time; this
release makes no universal timing guarantee. The portable package targets
Windows x64 and is not a signed installer. Reminders remain local to the
Windows user, with no cloud sync or closed-application notifications.

See [executable export scenarios](https://github.com/qinyuanhao17/MetrologyWorkspace/blob/v4.0.0/docs/features/excel_export.feature).
