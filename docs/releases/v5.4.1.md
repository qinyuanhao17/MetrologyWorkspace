# Metrology Workspace v5.4.1

Windows 10/11 x64 请下载同一发布页上的 `MetrologyWorkspace-v5.4.1-Windows-x64-Setup.exe`。安装包适用于当前用户，附带 SHA-256 校验文件。

- Match Workbook 的 Data selection 会在编辑、整表替换、切换 Preview / Final 和保存重开后保留。记录移动时，排除状态随记录走。暂时缺失的排除点重新出现时会恢复。
- Correlation and Trend 先恢复工作簿的 Data selection，再恢复已画的图。旧 WKB 中保存的 Reference 列别名也会迁移，保留对应的绘图选择。
- 自动化回归测试已更新到手动 Parameter Mapping 流程，显式配置每个用例需要的映射。

## 验证

- 全量测试运行 1,605 项，1,581 项通过，22 项因缺少指定 SME 样本跳过，0 项错误，2 项耗时断言失败。全量中 Trend 滚轮缩放最慢一次为 300 ms，阈值为 100 ms。Wafer Map 打开耗时为 408 ms，阈值为 400 ms。
- 同机单独复测三轮，Trend 滚轮缩放在 v5.4.0 和 v5.4.1 均为 48–49 ms。Wafer Map 打开在 v5.4.0 为 401–487 ms，在 v5.4.1 为 421–479 ms。测试仍使用原有阈值。
- 9 份实际 WKB 副本通过保存、重启和继续粘贴验证。重复替换 4 片和 8 片 wafer 数据时，Correlation 的测点与 Raw 数据逐点一致。最大样本恢复全部 773 个排除点。
