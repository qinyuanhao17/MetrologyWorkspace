# v3.1.0 — 正式源码标签

日期：2026-10-11。版本由 `VERSION` 和 annotated Git tag `v3.1.0` 标识，源码在 `main` 维护。
本次仅推送源码与标签，不另建 GitHub Release、不生成 EXE 或便携包、不移动旧标签。

## 更新

### 命名分析窗口
- Wafer Map / Correlation and Trend / Dynamic 三种工具的 Preview / Final 入口改为"按钮 + 复选下拉"：
  左侧打开或唤起该阶段所有勾选窗口，右侧新建并用原生复选框管理命名窗口，双击条目或 F2 重命名。
- 每个命名窗口拥有独立源表、选择与绘图状态，名称与勾选随 WKB 保存；Preview / Final 名单分开，
  窗口用稳定 UUID 标识，改名不影响已保存数据。
- Workbook Save 接受当前草稿，子窗口 Save 只接受本窗口草稿；recovery 保留每个独立草稿。

### 表格与剪贴板
- Ctrl+A 只选有内容的矩形（含表头行）；Ctrl+X 用流动虚线标记并在成功后立即清空，一次 Ctrl+Z 精确恢复。
- Ctrl+V 只保留原生选区与尺寸提示；内容与尺寸不一致时先询问"覆盖范围 / 清空重贴 / 取消"，
  不再出现粘贴提示条与额外颜色标记。
- 结果/配置表可复制不可剪切；过滤与排序始终按真实源行映射。

### 元数据锁与 Workbook 数据
- Wafer Map 与 Correlation/Trend 的数据表右侧提供 Reference / Raw 两套 Metadata locks；
  锁定列不会被范围粘贴、整表粘贴、直接编辑或剪切覆盖，缺失列在整表粘贴时按原位置追加。
- 子窗口可从 Workbook 复制数据（Data 菜单 `Copy from WKB`），File 菜单不再提供重复入口，
  Dynamic 保留其唯一显式恢复命令；打开已有 WKB 时先读取保存的范围选择再取行。

### 绘图与图注
- Groups → Plot labels 为 Trend / Wafer Map / Radius 提供 PAD 与 Lot ID 图注开关；
  仅影响 wafer 图注文本，不改身份列、分组、Data selection 或数值。
- Match 标题使用 Parameter 名称；Trend 主 Y 标签与标题一致；混合单位比较的警告保留。
- `Expand Wafers`：按每个 Wafer / Lot / PAD 身份所需宽度紧凑展开，横向滚动只在需要时出现；
  未分类的 Trend 在展开时按身份逐个收集绘制，收起后完全恢复所选顺序；保存的 Trend order 不变。

### 趋势顺序与参数导航
- Groups 增加 `Original row order` / `Original Wafer order`，有分类时提供 `Group → Wafer → Die Seq`；
  只改变显示顺序，不改源表、参与范围或拟合结果。
- Correlation / Trend 的参数导航支持 Ctrl 多选（含键盘 Ctrl+Space），ALL 与单选语义保留，
  多选状态随 WKB 保存，旧单选值兼容。
- 参考列增加源列与重复 mapping 行支持；每个 mapping 行保留自己的名称、Raw 列、Use、Card 与 Bias limit。

## 验证与边界

- 发布源码在本机隔离设置下运行 `python run_tests.py`：**693 项，0 失败**；唯一错误是沙箱内
  `os.link` 被拒绝的 `test_storage_v2.test_copy_cannot_overwrite_owner_or_samefile_alias`，
  该用例在沙箱外单独运行通过。`main.py --self-test` 退出码 0，改动文件 `git diff --check` 干净。
- 七个桌面 WKB 的隔离副本验收通过：命名窗口独立保存/重开；Reference 源列与重复 mapping 行；
  紧凑展开；Expand Wafers 收集身份（`matching-analysis_nova_multi_param.wkb` 1,964 → 255 条图注，
  `matching-analysis_nova_testfilter1.wkb` 1,647 → 255，展开 0.41 s、收起 0.30 s），
  原文件与 `config/settings.yaml` 的 SHA256 未改变。
- 只读验收使用隔离副本，不修改桌面原文件；不改变插值、拟合算法、色标、参与身份与 WKB 存储格式。
- 已知限制：WKB 首次打开、子窗口恢复等前几版遗留的多秒优化仍未完成；
  性能回归用例中的固定阈值在明显负载下可能波动，本版未放宽任何阈值。

各专项验收与数据见 `docs/plans/` 下同期文档；前版更新见 [v3.0.2 发布说明](v3.0.2.md)。
