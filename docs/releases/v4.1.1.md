# v4.1.1 — Scoped editors and compact analysis exports

Date: 2026-10-22. Tag: `v4.1.1`. Application `VERSION`: `4.1.1`.

## Changes since v4.1.0

- Raw Data floats above its Match Workbook and analysis windows, not unrelated
  applications. Activating Raw does not bring the Workbook over its analysis
  windows. Modal confirmation prompts retain priority.
- Wafer Map / Radius and both Correlation and Trend source panels support
  double-click float/dock, scoped only to their own analysis window. Dynamic
  Measurement uses the same owner-local behavior. These are the original live
  editors: model, source rows, copy/paste, Undo and plot connections are retained.
- Dynamic All Dies and Single Die Add Compare use independent Y axes for
  different parameters. All dies of one parameter share its axis. Cycle plots
  remain available in the application and PNG export.
- All Match sheets follow the supplied layout: horizontal parameter tables,
  Match/Trend/Bias plots underneath, and literal Original source data to the
  right. Group and Wafer views retain formula links to Original source rows.
- Dynamic Excel sheets retain literal sources, editable Cycle-by-Die pivots,
  formula-linked 3 Sigma results and native editable Sigma charts. Parameter
  charts are vertical; the combined table and chart are top-aligned to their
  right. Redundant per-Die Cycle line charts/support tables are not exported.
- FM embeds the complete current Copy PNG grids: Wafer Map on the left, Radius
  on the right. No per-parameter cropping. PNGs keep their aspect ratio and
  remain bounded to 7.5 cm high / 18 cm wide. TEM's additional FM Trends remain
  below the PNG row. Native and Matplotlib reports share this layout. Static
  PNGs do not recalculate when Excel source values change; native Dynamic and
  Match charts do.
- Closed saved Dynamic and Map workspaces export through the ordinary restore
  pipeline without attaching windows or accepting drafts. Legacy saved draw
  selections no longer disappear under a new empty window's defaults.
- Hidden excluded source rows have visible gap boundaries and original-row
  tooltips. Table dimensions refresh with actual document and visible extents.
  Partial pastes edit only corresponding visible rows; overflow is rejected,
  unhide restores excluded records, and Undo remains source-aligned.
- Repeated OCD case pasting retains mapped Raw columns and literal precision,
  fixes stale mapping controls after header changes, and retracts only rows
  added by a misplaced paste when that pasted rectangle is cut. Ordinary paste
  remains an overlay, not silent whole-document replacement.
- Reference recognition tolerates independently identified unequal-length
  tables and recovers after identity columns are supplied. Invalid headers in
  one source do not block valid plots from the other. Cross-source fits still
  require aligned rows; no pairing or regression semantics were changed.
- Match equations and R-squared are selectable/copyable. Correlation Ctrl+Alt
  supports multiple parameters with each unordered pair plotted once; REF and
  RAW remain distinct sources even for equal parameter names.
