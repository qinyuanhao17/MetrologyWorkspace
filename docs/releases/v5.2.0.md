# v5.2.0 — Reference Alignment and Die Maps

Windows x64 current-user Setup release. Source tag: `v5.2.0`.

## Reference Summary

- Summary, Wafer Alignment and XY Bias Trends tabs.
- Editable Ref/Raw tables share Match WKB's spreadsheet UI; Raw supports direct Ctrl+V without a separate Paste button.
- Whole-wafer reordering, fixed Raw order by default, explicit one-to-one links and stable coordinate sorting.
- Ref coordinates convert into the selected Raw unit before calculating Raw minus Ref. Missing coordinates/units and unequal point counts produce explicit errors without truncation or interpolation.
- Default two-column Trend layout; ordinary wheel scrolls, Ctrl+wheel zooms, no Add Compare.
- Multiple source folders; NOVA trailing empty fields and consolidated LBH flags; Windows long-path support for PMISH recipe outputs; explicit CDSEM MP coordinate selection.

## Spectra and Match Workbook

- Spectra tree sorting with double-click restoration of original order.
- Parameter mapping offers a read-only out-of-range Die Map using Raw/cached coordinates without loading spectral arrays. Outliers are red; context is gray.
- Shared Die Maps use regular-weight titles, equally padded circular frames, closer Die labels and a single-tile minimum window width.
- Field-based light-gray PAD grid fills the wafer and clips at its circumference, preserving measured point positions.
- Taller mapping rows and Draw-first Single wafer matrix.

## Verification and packaging

The four supplied vendor archives and the actual JC1913 workbook have separate
real-file validation records. Source tests use isolated settings and normal
Windows TEMP; AutoWeighting remains deferred and its three test modules are
excluded. The final release regression result is recorded in the Release
attachments.

Setup is built from an isolated archive of the exact release commit. Personal
settings, SME files and workbooks are excluded. Build provenance, validation and
SHA-256 checksums accompany the installer. The executables are unsigned.
