# v5.1.1 — Reference Summary

Version 5.1.1 is supplied as a Windows x64 current-user Setup installer and a
portable ZIP. Download from the [GitHub Release](https://github.com/qinyuanhao17/MetrologyWorkspace/releases/tag/v5.1.1).
Extract the complete portable ZIP before starting `MetrologyWorkspace.exe` and
keep `_internal` beside it. Both formats contain the same application files.

## Reference Summary

- The main window has a new independent **Reference Summary** tool.
- NOVA, PMISH and KLA CSV exports and CDSEM1 Excel workbooks use the supplied
  vendor-specific merge and validation rules.
- Source files are never modified. Work runs in the background, supports
  cancellation and publishes completed outputs to the selected folder.
- The window shows compact file, row, channel or MP, issue and output summaries.
  It deliberately does not display a 100-row measurement preview.

## Spectra corrections

- Spectra Info follows current Workbook Reference/Raw edits, stage changes and
  reloaded spectrum metadata while preserving participation and plot state.
- Mueller plots display one-based matrix captions from M11 through M44 without
  changing their internal data keys.
- Checked SME export omits the common source-root folder while retaining its
  internal directory structure.

## Packaging

The portable application and Setup are built from an isolated archive of the
exact annotated `v5.1.1` tag. The Conda SQLite runtime and offline OCR runtime
are bundled. Personal settings, workbooks, SME measurements and local validation
files are excluded. Release assets include SHA-256 checksums and build/validation
provenance. The executables are unsigned.

## Source verification

The complete suite ran 1,457 tests in 536.120 seconds. 1,456 passed; the only
error occurred before application code when a long-path test fixture could not
create its own source file under an already long temporary-directory prefix.
That exact test passed with a short absolute TEMP root. Reference Summary,
Spectra, AutoWeighting/OCR and installer-wrapper tests passed.
