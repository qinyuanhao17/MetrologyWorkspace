# v5.3.0 — Workbook loading, selection and Groups

Windows x64 current-user Setup. Source tag: `v5.3.0`.

- Match Workbook has a dedicated **Data → Data selection…** entry, matching the
  other analysis windows. Filtering, checks, scripts and participation are kept.
- Recent Workbook lists read metadata only; routing avoids duplicate loads.
  Native SQLite fetch and deferred spectral frames reduce unnecessary sample
  materialization, preserving save/recovery validation and original data.
- Selection Script transfers filter conditions, checks and view state by
  Wafer/Lot/PAD/Die; Spectra Info adds XY, live shared Test Flags, original Raw
  order and editable report-column projection with Undo/Redo.
- Spectra Groups/Marks include POR defaults for new local configurations,
  Replace/Append composite Marks, one-time WKB copying and compact identity
  tables. Explicit magenta Highlight persists, and plot-local U unchecks curves.
- Correlation and Wafer Map share the updated Group editor; Correlation Ref/Raw
  metadata locks persist and protect linked Raw refresh. Wafer Map displays
  Group/Wafer/Lot/PAD without splitting populations and adds measured Sigma.
- Wafer Map automatically reduces wafers per page to respect the 120-map budget,
  retaining all selected parameters. Real JC1913 first/last pages were verified.
- Reference Summary supports CSV/Excel for all vendors; CDSEM1 accepts a single
  wafer with missing Lot/Wafer IDs without inventing identities.

## Validation scope

The user explicitly deferred the full suite. This release uses focused related
regressions and isolated build/package checks, documented in the attached
validation reports. AutoWeighting and OCR validation remain deferred; do not run
the all-component `--self-test` for this release. Earlier release full-suite
results are historical, not evidence of a full v5.3.0 regression.

Setup is built from an immutable isolated source snapshot. Personal settings,
workbooks and SME files are excluded. The installer is unsigned; package hashes
and any local Windows runtime-policy limitations are documented in the Release.
