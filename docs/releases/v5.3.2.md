# v5.3.2 — Spectra Highlight, Die Map selection and Reference import

Based on `v5.3.1`. Existing tags and installers are preserved.

- Persistent Highlight uses a white 7.5 px halo and bright orange-red
  `#FF3D00` 3.2 px core, independent of Channel Color. Ordinary selection
  retains its previous appearance. Clear Highlight clears all persistent
  marks in one undoable action. Legend, all 16 Mueller panels, both axes,
  large batches and floating plots follow the same style.
- Highlighted Die Map points change fill color while retaining their size
  and border. Unpinned Die Map windows no longer raise over Spectra Viewer
  when the viewer is activated.
- Die Map adds separate selection Undo/Redo buttons and Ctrl+Z /
  Ctrl+Shift+Z, plus Copy Select and Paste Select. Physical Wafer/Lot/PAD/Die
  identities transfer selection between WKB and Spectra Viewer without
  changing checkbox participation or TestFlag. WKB outlier maps can select
  points strictly beyond their current limits with Select Out of Range.
- Correlation/Trend rebuilds Reference wafer identities from the current
  edited metadata. Its Reference table reports actual rows and columns.
  Value-only Ref tables regain their default Raw identity when row counts
  are corrected through grid edits; this is derived for analysis without
  rewriting source cells or clearing Undo.
- CDSEM flat results retain per-MP absolute coordinates and all available
  extra source fields even when Wafer ID is blank; missing identities and
  units are not invented.
- KLA Offline Reference scans past long per-channel settings sections while
  retaining validation of malformed measurement tables. The four available
  real KLA files and a 220-line settings fixture pass. The user's specific
  failing Offline file is still needed for final format verification.
- Spectra Group Settings adds Set Test Flag using the existing assignment
  dialog and script semantics. Apply Script has a black background.
- Large plain-table saves use the existing background SQLite I/O path.
  Conflict detection, backups, atomic replacement and fsync remain enabled.
  First-save settings persistence can still cause a pause.
- Raw cell editing captures original values once for Undo. State comparison,
  grouping-state copies and plain Writer-cell serialization avoid repeated
  Python work while preserving literal values and validation.
- Preview Dynamic and Wafer Map discard unavailable non-finite Card
  coefficients from their applicable settings when a selected subset cannot
  be fitted. Original measurements remain untouched and JSON validation stays
  strict. Participation exclusions are saved as a typed state object, with
  compatibility for older in-memory list states.
- First paste into an empty Preview/Final stage remains available while Hide
  Excluded is active; selections transfer by existing record identities.
- Map Font adds 4, 5, 6 and 7 point choices, including smaller native/export
  headings, axis text and point labels.

## Validation

See [visual and real-data validation](../validation/spectra-highlight-2026-11-16.md)
and [release regression record](../validation/v5.3.2-release-2026-11-17.md).
Missing original mixed-instrument SME fixtures are explicitly skipped and
can be supplied with `METROLOGY_SME_SAMPLE_ROOT`; no replacement data or
relaxed performance thresholds are used to manufacture a passing result.

The Windows Setup is unsigned. Verify its SHA-256 against CHECKSUMS.txt on
the release page. Install, reinstall and uninstall validation uses an owned
scratch directory and does not replace the user's installed application.
