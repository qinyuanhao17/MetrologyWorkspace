# v5.1.0 — Spectra Viewer and Die Map

Version 5.1.0 is supplied as a Windows x64 current-user Setup installer and a
portable ZIP. Download from the [GitHub Release](https://github.com/qinyuanhao17/MetrologyWorkspace/releases/tag/v5.1.0).
Extract the complete portable ZIP before starting `MetrologyWorkspace.exe`;
keep `_internal` alongside it. Both formats contain the same application files.

This replacement of v5.1.0 is explicitly requested by the user after fixing two
recorded regression errors. Re-download Setup/ZIP if you obtained the first
v5.1.0 build; BUILD-INFO identifies the corrected source commit.

## Spectra workflows

- Spectra Viewer is available independently and inside Match Workbook, with
  matching UI and independent `.spec` files. Managed Ctrl+S / Ctrl+Shift+S save
  the owning Workbook; child titles show their actual saved document.
- Selection Script and one-time Copy WKB Selection copy checks, all filter
  conditions, search, view mode and Hide excluded rows. Identity matching uses
  Wafer ID, Lot ID, PAD Name and Die. Renamed SME files are supported; conflicting
  repeated business identities are reported. Checked/Unchecked row views follow
  actual participation across the complete data, including manual tree changes.
- Spectra Info follows Raw Data Original row order for current checked spectra,
  with original Reference column names and optional Test Flag column. Time comes
  from SME metadata. Filename timestamp verification is enabled by default in
  Options. Unmatched or ambiguous records are reported before CSV export/copy.
- Test Flag offers grouping, search, editable integer classifications and bulk
  assignment, with 0 as fallback. Marks and Test Flag selectors avoid accidental
  wheel changes. Die Map shows a small green flag for 1, red for −1 and none
  for 0; point color independently represents spectrum participation.
- Original SME export copies existing files into their source folder layout.
  Missing/unavailable originals offer Retry or Skip and a final list. Existing
  destinations are protected. Completion shows green bold Export Succeeded√
  or red bold Export Failed×.

## Die Map and rendering

Die Map supports left-drag point selection inside one wafer, additive Ctrl/Shift
selection, double-click participation changes and blank-space deselection.
Unchecked points stay light gray. Fixed-size cards use scrollbars when the
window shrinks; check/flag changes reuse the existing page and view ranges.
Map and expanded spectrum windows support floating pin behavior.

Wafer outlines, points, selection rings and Test Flag glyphs use antialiasing.
Apply Check To Similar Wafer and Apply Flag to Similar Wafer act independently.
Similarity requires the same Die ID set and corresponding X and Y differences
each strictly below 0.4 mm, with explicit handling of missing/conflicting data.

Legend context menus offer Show All, Hide All and Select Channel. Whole-channel
hide/show retains batch arrays and cached images. Geometry changes keep Qt
painting enabled while background workers prepare the new image; full source
data remains authoritative for calculation, bounds and native export. Large
document I/O and decoding keep the GUI event loop responsive.

## Save size

Options → Spec Save Type offers exclusive Embed Spectra Data and Spectra Paths
Only modes for both `.spec` and managed Workbook storage. Saving after switching
to paths removes embedded samples from the new container. Paths require the
original files at their saved locations; unavailable references and their
check/flag states are retained. The ordinary previous-version `.bak` is kept.

On the supplied 1,890-spectrum fixture, an isolated copy decreased from
409,559,040 to 2,867,200 bytes, with exact agreement of every numeric and
wavelength array after reading the original files. A subsequent path save took
114.5 ms. Channel re-show observations decreased from approximately 50 seconds
to 0.6 seconds. These are local measurements, not universal timing guarantees;
initial loading and new-size image generation still take measurable time.
See [performance/storage validation](../validation/spectra-performance-storage-2026-11-03.md).

## Verification and publication

The corrected source passed **all 1,421 authorized regression tests in
528.043 s**, with no failures, errors or skips. AutoWeighting/OCR remains
explicitly excluded. The internal preparation remains read-only, public table
copies remain independently editable, and Correlation factories no longer need
to expose the standard window's optional `raw_model` cache. Both originally
failing tests pass. The earlier antialiasing-focused run passed 47 tests. See
[regression repair validation](../validation/regression-two-errors-2026-11-04.md).

Source regression success is separate from frozen/installer runtime checks.
This host previously blocked unsigned executable startup with Windows signing
policy WinError 4551. The replacement BUILD-VALIDATION records actual artifact
results and any continuing policy block without marking blocked checks passed.

Builds use an isolated archive of the exact release commit, bundle the Conda
SQLite runtime and exclude personal settings, workbooks and SME files. Setup
install/reinstall/uninstall validation uses an owned directory and checks
user-file preservation when execution is allowed. Release assets include SHA-256 checksums and build
provenance. The executables are unsigned.

CXMT is synchronized by fast-forward to the corrected release commit. The
v5.1.0 tag is replaced with explicit user authorization; main and all other
historical tags retain their previous commits. See [v5.1.0 validation](../validation/v5.1.0-2026-11-04.md).
