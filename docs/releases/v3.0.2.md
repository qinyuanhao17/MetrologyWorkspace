# v3.0.2 — 正式源码标签

日期：2026-10-09。版本由 `VERSION` 和 annotated Git tag `v3.0.2` 标识，源码在 `main` 维护。
本次仅推送源码与标签，不另建 GitHub Release、不生成 EXE 或便携包、不移动旧标签。

## 更新

- Correlation 每张图右上角增加 `Swap X/Y`，独立切换，再次点击恢复。
- 用同一批配对观测重新拟合新 Y 对新 X，不将旧斜率取倒数；源字符串与行映射不变。
- 原位更新目标图的点、拟合线、标题与坐标标签，不重建其他图或改变其缩放。
- Reference / Raw Data 独立记住方向；参数筛选、数据更新、保存恢复和导出使用同一选择。
- 切换方向会标记文档未保存；旧文档没有方向字段时使用默认轴。Pending Draw 不因恢复方向而强制绘制。
- Copy PNG 不包含新增按钮，复制完成后恢复按钮。

## 验证与边界

发布功能代码在隔离本机临时目录运行 `python run_tests.py`：**587 项全部通过，252.610 秒**。
更新版本说明后，使用独立 scratch 设置执行 `main.py --self-test` 成功。
新增六项测试覆盖反向拟合、独立切换、源数据保真、更新与筛选、正式保存重开、Pending Draw 和复制图像。
首次全量出现的测试窗口清理错误已复现并修正，仅改变测试夹具关闭流程，没有修改 recovery 安全合同。

固定桌面 NOVA WKB 的 7,731 行真实数据，在 100% / 150% Qt 缩放下验证单图切换；
其他图控件与缩放、完整源表及导出方向检查通过，原 WKB 和用户设置哈希未改变。
这是离屏 Qt 验证，不是所有硬件或原生 Windows 帧率保证；不改变插值、拟合算法或保存格式。
WKB 首次打开等前版尚未完成的优化未在本次发布中宣称完成。
