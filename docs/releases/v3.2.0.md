# v3.2.0 — Current source snapshot

Date: 2026-10-16. This source-only release synchronizes the current application
before the independent reminders feature and the next NOVA export fixes.
It does not include new Windows binaries or modify earlier tags.

## Included changes

- Separate Export Excel (editable native charts) and Export Matplotlib
  (pictures embedded in XLSX), including available Preview and Final stages.
- Original source-order sheets and formula-linked Group and Wafer reports;
  source strings, participation identities and software calculations are retained.
- Individual physical-size chart panels, square native Excel charts, readable
  expanded Wafer labels and existing FullMap Wafer Map / Radius pictures.
- Named analysis windows can be opened with one click and deleted explicitly;
  new windows start empty, while the default KLA/NOVA window keeps Copy Raw Data.
- Correlation pair selection, symmetric-pair deduplication and stable grid layout.

## Known limits

- Large NOVA multi-parameter exports have been reported as very slow or not
  completing through the menu. This report remains open in this snapshot;
  fixes and representative before/after measurements follow this tag.
- Independent home-screen reminders and row-context Parameter mapping deletion
  are not included yet.
