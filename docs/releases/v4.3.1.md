# Metrology Workspace v4.3.1

Date: 2026-10-26. Tag: `v4.3.1`. Application `VERSION`: `4.3.1`.

Windows x64 release containing the grouped Excel export corrections since
v4.3.0. This tag does not publish `main` or create a release branch.

## Changes

- Native Group/Wafer Trend, Bias and Bias % charts now use cell-bound XY
  scatter series for their non-uniform horizontal geometry. A Show Wafer
  Group's calculated width now changes the plotted data as well as its footer
  captions and separator lines. X and Y ranges remain selectable and editable
  in Excel.
- Wafer captions remain centred over their own spans. The collision pass no
  longer applies a fixed chart-relative gap that pushed many correctly
  positioned labels across unrelated spans.
- Every individual `Match <Group>` sheet now contains that Group's complete
  Wafer detail regardless of Show wafer. `Show wafer` only selects which
  per-Group detail width is used by the combined `Match Group show Wafer`
  sheet.
- `Match Group` remains Group-only. `Match Wafer` now contains every visible
  Group and Wafer in one complete chart; page-specific Trend, Bias and Bias %
  panels and `Page x/y` titles are removed.
- Numeric Trend/Bias panels show one `Die Seq` title. Tick candidates are
  sampled within each visible Group/Wafer span instead of using one global
  step that skipped whole Wafers and produced alternating labels.
- Native Excel and Matplotlib exports continue to share physical panel widths,
  footer boundaries, line/marker styling and source values.

## Hover coordinate limitation

The visible tick labels are Die Seq. On multi-Wafer Group/Wafer charts, the
native Excel hover X value is the internal display coordinate required to keep
Wafers side by side and to preserve unequal Group/Wafer widths. Using raw Die
Seq as that numeric value would overlap wafers because each Wafer restarts at
Die 1. `Match Original` uses a category axis and therefore displays Die Seq in
hover, but it does not carry the non-uniform Group/Wafer geometry.

## Verification

The focused Excel, Matplotlib, WKB-axis, sheet-selection, opening-layout and
release-export suites passed **98/98 tests**. Coverage includes:

- one complete Match Wafer chart without `Page x/y`;
- one Die Seq title on numeric axes;
- dense span-local Die Seq tick candidates for every visible Wafer;
- cell-bound XY ranges and editable source selections;
- Wafer caption centres, non-overlapping labels and Group-only composition;
- identical identity panel widths between native Excel and Matplotlib.

The full suite ran **1,089 tests**. The five failures in the loaded full-suite
run were re-run in isolation: the recovery-directory timing test and three
performance tests passed; two existing strict wall-clock thresholds remained
above their limits by about 9 ms and 17 ms on this host. These thresholds are
not presented as performance improvements in this release.

PyInstaller produced 1,544 payload files. The ZIP passed its CRC check and every
extracted-file SHA-256 matched the build manifest. A fresh owned silent
installation matched all 1,544 file hashes and reported installer
`ProductVersion=4.3.1` / `FileVersion=4.3.1.0`. Portable, extracted and installed
`--self-test` runs all exited 0. The owned uninstaller removed only shipped
application files and preserved settings, WKB and MWKB sentinels.
