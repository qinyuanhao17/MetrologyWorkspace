# v3.0.1 — 正式源码标签

日期：2026-10-09。版本由 `VERSION` 和 annotated Git tag `v3.0.1` 标识，源码在 `main` 维护。
本次仅推送源码与标签，不另建 GitHub Release、不生成 EXE 或便携包、不移动旧标签。

## 更新

- Ctrl+C/X 显示流动虚线；可编辑来源表支持复制成功后立即剪切，一次 Ctrl+Z 精确恢复。只读结果/配置格不能被剪掉。
- Ctrl+A 仅选择已有数据矩形；Ctrl+V 使用原生选区，不加额外颜色、实线框或 Show changes。
- Wafer Map 和 Correlation/Trend 表格右侧增加 metadata 锁；保留锁定源字符串与列名，整表粘贴按原行位置保留。
  行数不符或重复列名时拒绝粘贴，锁定状态随 WKB 保存；新建/打开时移除已不存在字段的旧锁。
- Correlation/Trend 顶部增加 parameter 与 ALL 筛选，复用绘图控件；包含比较曲线，筛选后的 rank、页数和导出一致。
- Wafer Map 实测点悬停显示真实 Die；缺坐标和无效值过滤不改变 Die 对应关系。
- 修复 Dynamic 剪切的显示精度截断、筛选缓存的 rank 错位和拒绝粘贴前清空 Correlation 来源上下文的问题。
- 减少 Raw Data 重复准备与控件重建，合并连续键盘编辑后的派生更新；源数据和单步撤销立即生效。
