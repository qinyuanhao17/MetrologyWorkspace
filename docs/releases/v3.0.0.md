# v3.0.0 — 正式源码版本

日期：2026-10-08。版本由 `VERSION` 和 annotated Git tag `v3.0.0` 标识，源码在 `main` 维护。本次不生成 Windows EXE、安装包或便携包；旧版本与开发版标签不移动。

## 主要内容

- Match Workbook 支持 KLA / NOVA / TEM、多 Reference 参数映射、独立 Preview / Final 输入、Card、Bias、单 wafer 指标与绘图。
- Head / Mark 分类、组合 Group、Group plots、三表参与选择和筛选；保留未参与记录的源数据与身份。
- Wafer Map / Radius、双来源 Correlation / Trend 和 Dynamic 的独立窗口与文档工作流。
- Typed SQLite 工作区、保存/恢复状态、独立子稿保护、后台 recovery，以及主窗口可设置的 recovery 检查周期。
- Raw Data 全选与单格操作、映射切换、热态 stage/Group 更新、Trend 绘制与滚轮优化；减少重复准备、重复绘图与状态复制。
- 修复 Map 延迟 Fit-width 覆盖显式视图、恢复时旧排队任务违背 Pending Draw 状态等问题。保留源字符串、行映射、统计、导出与视图语义。

## 验证

发布前执行 `python run_tests.py`，536 项测试全部通过；既有 Correlation 恢复 2 秒门槛未放宽。7 个桌面 WKB 与 3 个 sample CSV 通过独立公式、完整 snapshot 往返与文件哈希检查；1× / 1.5× 缩放的边界与全分辨率曲线像素等价测试通过。测试设置、recovery 和衍生 WKB 均使用 scratch，未写回原数据或 `config/settings.yaml`。

离屏实测的 NOVA Trend 首次完整绘图中位数为 1.65 → 0.92 秒；Ctrl+滚轮完整曲线 P95 为 76.9 → 29.9 ms。数据、方法及完整结果见 [控件响应验证记录](../plans/control-responsiveness-results.md)。这些数字不是原生 Windows 帧率保证。

## 已知限制

- 首次 WKB 打开、首次 Preview / Final 切换、改变 Group 后 Apply、首次子窗口恢复和 Map GUI 绘制仍有同步阻塞；尚未实现完整的文档级后台分析/加载调度。
- 同一 NOVA 夹具从 shell 首次打开完整主图约 3.05 秒；含已保存 6 参数图的 Correlation / Trend 首次恢复约 4.90 秒。4 张保存 Map 的完整恢复约 2 秒。这些夹具不同于通过的原 2 秒恢复回归测试。
- 正式 WKB Save 仍同步；没有用后台 recovery 替代正式保存，也没有改变锁、revision、校验、原子替换或 Save / Discard 安全合同。
- 尚未完成原生 Windows 长会话或新 EXE 验证。全量测试仍会记录既有 modal timer warning 与预期失败路径诊断，不能将测试成功解读为零告警或不存在其他潜在 bug。

后续优化继续参照 [控件响应优化方案](../plans/control-responsiveness-optimization.md)，不以占位界面、缩短数据或只测热态冒充完整完成。
