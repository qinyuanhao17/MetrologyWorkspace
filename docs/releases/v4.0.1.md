# v4.0.1 — AutoWeighting Writer and source-aware analysis

Date: 2026-10-20. Tag: `v4.0.1`. Application `VERSION`: `4.0.1`.

The user explicitly approved publication with the seven elapsed-time test
limitations documented below. The suite is not fully green. No numerical

are not rewritten; only the new tag is pushed.

## Changes

- AutoWeighting Writer V1 is a fifth independent tool. It reads the two
  supported screenshot table layouts locally using bundled OpenCV/RapidOCR
  recognition, with editable candidates, explicit review, overlap/conflict
  handling, undo/redo, `.waw` projects and literal Excel/TSV export. See
  [the workflow and limitations](https://github.com/qinyuanhao17/MetrologyWorkspace/blob/v4.0.1/docs/auto_weighting_writer.md). Recognition
  does not execute constraints or infer unseen values/checkbox states.
- REF and RAW parameter buttons are independently selectable, in distinct
  source panels. Same-named columns remain different parameters. Correlation
  includes row-aligned cross-source pairs; the former 40-column/30-parameter
  caps are removed without removing pagination or export-size protections.
- Ref Data starts empty/manual. Copy from WKB follows only Raw, including
  values and column names, without replacing manual Ref or its identities.
  Local Raw edits detach the link and are retained even when Save occurs
  before the next Workbook refresh. Restored linked windows follow current
  Workbook classification rather than stale whole-window ownership flags.
- Trend sources without a recognized Die Seq column use their own visible
  sheet row numbers, starting at 2. Filtering preserves gaps. Screen and PNG
  axes use Row Number or Die Seq per source; the exported data preserves the
  same coordinates. Existing blank Die Seq cells keep their missing-value
  behavior. Source strings and source tables are not rewritten by drawing.
- Wafer selector changes no longer reload edited Ref cells or clear their
  undo history. Group/Show Wafer captions retain the intended classification.
  The group display plan no longer requires populated manual Ref or a fit.
- TEM/NOVA/KLA accept shorter or partially blank Reference tables. Missing
  pairs do not enter fits or Bias calculations; Raw rows and positional
  correspondence remain intact. Interior omissions must retain blank rows.
- Copy-enabled old NOVA/KLA/TEM Map windows refresh from current Workbook
  data without overwriting local measurement drafts or saved Map snapshots.
- Installer wrapping accepts an explicit verified portable SHA-256 and
  version, retains exact-file uninstall protection, and verifies the payload
  before calling NSIS. The original v4.0.0 wrapper defaults remain supported.
