# Metrology Workspace v5.4.0

Windows 10/11 x64 请下载安装包 `MetrologyWorkspace-v5.4.0-Windows-x64-Setup.exe`。安装包适用于当前用户，附带 SHA-256 校验文件。

## 更新内容

- Spectra Viewer 按 SME 文件并行准备嵌入数据。**Options → Import Compression Threads** 支持 Auto 和偶数线程设置。读取与嵌入分开显示进度，Paths Only 跳过嵌入，取消或编码失败时保留现有数据。
- Spectra Viewer 支持选择多个目录，按绝对目录路径过滤或着色。Spectra Info 可隐藏及恢复列。
- Reference Summarizer 支持通过 File 菜单打开、保存和另存为 SQLite `.ref` 文件，恢复各 Ref output 的 Raw 数据、wafer 链接、列映射及绘图状态。
- XY Bias 默认三列，支持按 Raw、Ref 或 XY 排序查看配对结果。Data 和四个分析页随已绘制的 Ref output 更新。Copy Reference 可按 Raw 原始行序复制选中的 Ref 列。
- Match Workbook 的 Parameter Mapping 改为手工添加，换表后保留映射。Correlation and Trend 子窗口可单独启用 **Copy Ref from WKB**，默认关闭。
- Wafer Map 和 Correlation and Trend 支持双击移除测点，并通过右键撤销、重做或恢复测点。表格支持 Ctrl+Shift+方向键扩展选择。

## 验证状态

同机测量覆盖 `D:\spectra` 的 4,809 个 SME，其中 3,123 个可读取，另外 1,686 个被现有解析器识别为加密文件。四线程的嵌入准备中位数从 13.64 秒降至 5.07 秒，导入到 Viewer 可用的中位数从 27.58 秒降至 18.54 秒。串行和并行的嵌入记录内容及顺序校验一致。[实测方法和原始数据](../validation/spectra-import-compression-2026-11-19.md)

Spectra 导入和 Reference 工作区定向验证有 47 项通过、4 项跳过。开发工作树上的全量测试运行了 1,603 项，报告 26 项失败、417 项错误及 22 项跳过。392 条错误明确来自旧测试依赖自动生成 Parameter Mapping，其余问题仍待处理。
