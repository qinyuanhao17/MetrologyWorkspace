# Metrology Workspace v5.5.3

本版本集中完成 Match Workbook、Reference Summarizer、Group 设置和联动绘图的一致性更新。

- Match Workbook 新增主窗口 `Wafer Mean / Sigma` 结果页，只绘制 Parameter mapping 中勾选的参数。每个参数默认使用 Mean、Sigma、Mean Bias、Sigma Bias 四图，支持 Dock 重排、堆叠、拖动缩放并随 WKB 保存。
- Wafer Mean / Sigma 使用 Single-Wafer matrix 风格的横轴编号、三位小数 Y 轴、居中的参数标题、白色绘图区和受控 Group 分界线；Bias 以零为中心并保持正负范围对称。
- Correlation、Trend、Wafer Map、Radius 和 Wafer Mean / Sigma 支持同源测点联动：源图显示红圈，其他可见图显示黄圈。
- Data Selection、Group 定义和 Group 内 TestFlag 在 Preview/Final 切换、重新分析、子窗口打开以及 WKB 保存重开后保持。未 Apply 的 Group/TestFlag 会以 pending 状态保存，并在下一轮完整分析时应用。
- 子窗口未复制 WKB Data 时默认使用 Full data 且不跟随 WKB Groups；设置 TestFlag 或编辑 Group 会转为子窗口本地设置，不修改父 WKB。
- Group settings 的 TestFlag、Head、Mark、Group 等全部列支持筛选；Set Test Flag、右键设置、键盘粘贴和 Group Script 共用同一组 TestFlag 分配。
- Reference Summarizer 完善 NOVA、PMISH、KLA、CDSEM1 汇总，生成 measurements、Excel 审计工作表与 HTML summary；Ref/Raw 对齐、XY Bias、Ref WaferMap、Ref Radius、Correlation、Trend 和 Groups 使用同一参与行与源行身份。
- Reference Wafer Alignment 支持 Ref/Raw 双表 Ctrl 共同滚动、同步选区、按另一侧 Wafer 顺序重排、坐标标签解析和共享测点预览。
- 优化大规模 Wafer Mean / Sigma 首次绘制：真实 7731 行、3 参数、255 个 Wafer span 的桌面 WKB 从约 21.7 秒降至 0.63 秒。
- 全量测试：1691 项通过，22 项因仓库外 SME/Spectra fixture 跳过，0 失败。
