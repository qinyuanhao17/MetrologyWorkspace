# Executable scenario map

`card_matching.feature`、`dynamic_analysis.feature`、`application_shell.feature` 和 `trend_overlay_compare.feature` 保存业务语言；项目不额外引入 Cucumber 运行时。相同场景由现有 `unittest` 公共接口测试执行：

- Preview two mapped parameters → `MatchWorkbookTests.test_preview_generates_one_card_per_parameter_and_applies_it_lazily`
- Manually map a numeric Reference column without a suffix → `MatchingWindowTests.test_numeric_reference_columns_without_suffix_can_be_mapped_manually`
- Final data is not carded a second time → `MatchingWindowTests.test_final_mode_keeps_evaluated_values_equal_to_raw_data`
- Reopen a saved matching workbook and restore its layout/order → `MatchWorkbookTests.test_wkb_round_trip_preserves_source_tables_and_settings`, `MatchingWindowTests.test_wkb_restores_the_saved_setup_splitter_layout`, and `MatchingWindowTests.test_parameter_plot_order_survives_run_and_wkb`
- Load an older schema 1 workbook → `MatchWorkbookTests.test_schema_one_wkb_still_opens_without_fullmap_stage_tables`
- Apply a TEM Card to a later Preview FullMap → `MatchWorkbookTests.test_preview_stage_applies_the_match_card_to_separate_fullmap_rows`
- Open Final FullMap without applying Card again → `MatchWorkbookTests.test_final_stage_uses_separate_already_carded_fullmap_without_reapplying_card` and `MatchingWindowTests.test_preview_and_final_fullmap_open_in_the_existing_wafer_workspace`
- Persist the exact edited Map table inside WKB, default KLA/NOVA from matching data, and keep TEM Map input independent → `MatchWorkbookTests.test_wkb_round_trip_preserves_exact_map_tables`, `MatchingWindowTests.test_kla_map_edits_are_saved_in_wkb_and_not_regenerated`, and `MatchingWindowTests.test_tem_map_starts_empty_and_saved_map_is_restored`
- Persist independent Preview/Final Dynamic tables inside WKB → `MatchWorkbookTests.test_wkb_round_trip_preserves_independent_dynamic_tables`, `MatchWorkbookTests.test_schema_four_wkb_opens_without_dynamic_snapshots`, and `MatchingWindowTests.test_preview_and_final_dynamic_edits_are_saved_independently_in_wkb`
- Reopen Preview Map/Dynamic with their independent surviving selections → `MatchingWindowTests.test_reopening_preview_wafer_map_restores_its_parameter_selection` and `MatchingWindowTests.test_reopening_preview_dynamic_restores_its_parameter_selection`
- Save and reopen the entire WKB with independent Map/Dynamic sidebar selections → `MatchWorkbookTests.test_wkb_round_trip_preserves_workspace_selections`, `MatchWorkbookTests.test_schema_five_wkb_opens_without_workspace_selections`, and `MatchingWindowTests.test_reopened_wkb_restores_map_and_dynamic_sidebar_selections`
- Close Match-managed Map/Dynamic without a discard prompt and persist directly to the current WKB, while retaining the standalone safeguard → `MatchingWindowTests.test_closing_managed_wafer_map_saves_without_discard_prompt`, `MatchingWindowTests.test_closing_managed_dynamic_saves_without_discard_prompt`, and `WorkspaceTests.test_standalone_dirty_workspace_still_confirms_before_closing`
- Close a saved Match Workbook by persisting its current Map/Dynamic edits once and closing its Wafer Map, Dynamic, and Correlation child workspaces → `MatchingWindowTests.test_closing_match_workbook_saves_and_closes_all_analysis_workspaces`
- After the first successful draw, replace Data and automatically redraw the last independent Wafer Map and Radius selections without reopening either selector → `PlotWorkspaceTests.test_replacing_data_after_first_draw_refreshes_maps_without_selector`, `PlotWorkspaceTests.test_changed_selection_discards_first_stale_job_then_refreshes_last_draw`, and `RadiusTests.test_replacing_data_after_first_draw_refreshes_radius_without_selector`
- After the first successful draw, changing selector boxes automatically redraws Wafer Map and Radius Plot without another draw command → `PlotWorkspaceTests.test_changing_map_boxes_after_first_draw_refreshes_without_draw_click` and `RadiusTests.test_changing_radius_boxes_after_first_draw_refreshes_without_draw_click`
- Reopen successfully drawn Wafer Map or Radius Plot child windows (or their saved WKB) and automatically restore the last available boxes → `PlotWorkspaceTests.test_restored_map_draw_state_redraws_without_draw_click`, `RadiusTests.test_restored_radius_draw_state_redraws_without_draw_click`, `MatchingWindowTests.test_drawn_wafer_map_auto_restores_after_window_and_wkb_reopen`, and `MatchingWindowTests.test_drawn_radius_plot_auto_restores_after_window_and_wkb_reopen`
- Open the standard Correlation and Trend tool from WKB with separate Ref/Raw tables, row-aligned identities, all Raw columns, source-local fits, source-ordered panels, and Match-consistent orange/blue series → `MatchingWindowTests.test_correlation_button_opens_active_reference_and_raw_sources`, `MatchingWindowTests.test_default_correlation_button_reuses_the_standard_tool`, `CorrelationTests.test_standalone_ref_and_raw_tabs_build_row_aligned_source_plots`, and `CorrelationTests.test_workbook_sources_use_the_standard_tool_and_match_colours`
- Right-click to overlay two Trend parameters: same units share one axis while different or unknown units create a linked second Y axis → `TrendLogicTests.test_same_unit_parameters_share_one_axis`, `TrendLogicTests.test_unknown_units_use_a_second_axis`, `CorrelationTests.test_trend_context_menu_offers_overlay_for_checked_parameters`, and `CorrelationTests.test_overlay_merges_two_panels_into_one_widget_with_two_axes`
- Unlink a Trend overlay and return to one panel per parameter → `CorrelationTests.test_unlink_overlay_restores_one_panel_per_parameter` and `CorrelationTests.test_separate_panel_mode_still_renders_one_widget_per_parameter`
- Export a customer-facing result → `MatchingWindowTests.test_exports_excel_and_separate_plot_images_after_analysis`
- Reference-first state → `MatchingWindowTests.test_reference_is_loaded_before_raw_data_and_enables_analysis`
- Editable Reference/Raw spreadsheet grids → `MatchingWindowTests.test_reference_and_raw_inputs_are_editable_spreadsheet_grids`
- All-parameter vertical Card review with unclipped single-row plots and both Bias views → `MatchingWindowTests.test_analysis_results_share_the_scrollable_setup_workspace` and `MatchWorkbookTests.test_wkb_round_trip_preserves_source_tables_and_settings`
- Reserved Match heading for equation/R², four-sided interactive plot frames, and PMISH-versus-Match-Type Trend styling → `MatchingWindowTests.test_match_plot_shows_fit_equation_to_the_right_of_its_title`, `MatchingWindowTests.test_result_plots_show_four_sided_frames_and_use_box_zoom_mode`, `CorrelationTests.test_panel_borders_are_draggable_and_drag_zooms`, and `MatchingWindowTests.test_trend_and_bias_use_visible_point_lines`
- Shared PyQtGraph wheel behavior—ordinary wheel scrolls the enclosing page and Ctrl+wheel zooms only the plot—→ `CorrelationTests.test_interactive_grid_zooms_one_plot_and_resets` and `DynamicWindowTests.test_selected_parameters_render_separate_vertical_table_and_plot_sections`
- Aligned Match/Trend/Bias frames with equal-weight edges and no redundant Wafer title → `MatchingWindowTests.test_primary_plot_frames_align_and_omit_the_wafer_axis_title` and `MatchingWindowTests.test_result_plots_show_four_sided_frames_and_use_box_zoom_mode`
- Fixed Match width, uniform primary-plot height, and a four-plot row that fits without horizontal scrolling → `MatchingWindowTests.test_analysis_results_share_the_scrollable_setup_workspace`, `MatchingWindowTests.test_primary_plot_height_is_fixed_for_single_and_multiple_parameters`, `MatchingWindowTests.test_selected_primary_plots_share_one_horizontal_row`, and `MatchingWindowTests.test_four_primary_plots_fit_without_horizontal_scrolling`
- Activity restored at right and theme-aware coloured terminal Log placed below the main workspace → `ShellTests.test_log_spans_the_bottom_below_the_restored_activity_panel`, `ShellTests.test_terminal_log_records_runtime_component_and_error_information`, `ShellTests.test_light_theme_uses_a_light_fixed_width_terminal_log`, and `ShellTests.test_terminal_log_colours_level_labels_after_theme_switch`

- Preview/Final top mode tabs preserve results/layout and use independent Raw Data → `MatchingWindowTests.test_switching_preview_and_final_keeps_results_and_layout`

场景描述保持业务语义，自动化测试通过 `MatchWorkbook` 的稳定 interface 和 `MatchingWindow` 的用户可见状态验证；WKB 兼容测试不依赖 SQLite 的内部表结构。

`dynamic_analysis.feature` 对应 Dynamic 重复性分析：

- Dynamic run folder 和重复 Die 顺序的 Cycle 推断 → `DynamicDataTests.test_cycle_is_inferred_from_dynamic_run_folder_and_report_tail_is_removed`、`DynamicDataTests.test_cycle_fallback_handles_variable_die_and_cycle_counts`
- Cycle × Die Seq 透视表与样本 3σ → `DynamicDataTests.test_pivot_has_cycles_by_die_and_sample_three_sigma_bottom_row`
- 重复 Cycle/Die Seq 拒绝静默平均 → `DynamicDataTests.test_duplicate_cycle_and_die_is_rejected_instead_of_silently_averaged`
- 共用 Data 编辑器、上下独立滚动的逐参数表格，以及“横向紧凑 legend 的全部参数比较 + 各参数独立”的无数据点三列柱图网格 → `DynamicWindowTests.test_selected_parameters_render_separate_vertical_table_and_plot_sections`、`DynamicWindowTests.test_more_than_three_parameter_charts_wrap_to_the_next_row`
- Wafer Map 阵列不显示底部 RBF / edge / size 说明 → `ArrayTests.test_map_array_omits_interpolation_footer`
- 替换 Data 表时保留仍存在的 Dynamic 参数并刷新 3σ → `DynamicWindowTests.test_replacing_dynamic_data_keeps_available_parameters_and_refreshes_plots`；Wafer Map 共用行为由 `WorkspaceTests.test_replacing_table_keeps_available_wafer_and_parameter_selections` 覆盖
