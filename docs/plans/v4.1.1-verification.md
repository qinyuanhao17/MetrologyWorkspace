# v4.1.1 scoped editors and export verification

Latest user requirements supersede the prior system-topmost Raw flag,
per-parameter FM PNG crops and per-Die Cycle chart exports. The earlier dated
plans remain historical records; this record and v4.1.1 release notes describe
the new behavior.

## Feedback loops

`run_tests.py tests.test_v411_float_scope -v` initially failed both the exact
global-topmost flag check and the missing Map/Correlation editor controller
check (2 tests / 0.267 s). A separate native Windows harness checks actual
z-order and activation, not only flags. Ranked predictions were: removing the
system-topmost flag lets external apps cover Raw; removing the native Workbook
owner avoids raising its root over children; restricting activation handling
to the Workbook family avoids raising Raw for unrelated windows. Those scope
boundaries and modal-dialog priority have executable regression coverage.

Raw is an unowned ordinary Tool. Only while floating does its controller watch
Workbook-family activation and raise without activation. It never raises the
Workbook. Child measurement Tools are owned only by their own analysis window.
Close/dock paths retain the original editor and Undo; Qt teardown events are
guarded while Python is clearing cyclic controller attributes.

Three export tests were red for redundant Dynamic Trend capture, redundant
native charts, and individually named/cropped Map/Radius pictures. The report
writer now retains only editable Sigma plots and source/pivot calculations;
Cycle comparisons remain in the GUI. The combined table and chart have distinct
top-aligned areas. FM calls the same `png_bytes()` methods as Copy PNG without
touching the clipboard; tests compare complete native/Matplotlib picture bytes
with the live two-parameter grids, including an unmapped selected parameter.
