# 参数导航 Ctrl 多选

按用户截图中的 ALL / 参数按钮实现一起显示多个参数。

## 行为

- 普通点击仅显示该参数；Ctrl+点击增减一个参数。
- Ctrl+Space 可操作聚焦按钮；取消最后一个参数时回到 ALL。
- ALL 无论是否按 Ctrl 都显示全部；重复普通点击已选参数不会取消它。
- Correlation 显示含任一选中参数的已有拟合图；Trend 显示含任一选中参数的已有主曲线/比较曲线面板。
- 只筛显示，不改变源记录、参与范围或拟合；已有曲线、轴方向和手动缩放保留，导出沿用当前显示范围。
- 仍有效的多选参数在参数移除/换行时保留；全部移除或清空后回到 ALL/空导航栏。

## 实现边界

按 codebase-design 的共享接口原则，选择归一化及并集谓词集中在已有 `ParameterFilterBar`，
页面只查询匹配；复用原生按钮和原有缓存/渲染路径，不加依赖。
保存值仍使用原 `parameter_filter` 字段：ALL 为 null，单选为名称，多选为有序名称列表。
恢复通过显式 `set_selection`，不受当时是否按 Ctrl 影响；旧 WKB 的单选值兼容。
返回的列表是独立值，不会被外部修改污染当前选择或已接受快照。

## 验证

- TDD 三个垂直切片先红后绿：按钮增减、两个页面并集显示/导出、WKB 多选恢复。
- 36 项相关用例通过，覆盖普通/修饰键点击、键盘、失效名称、清空、图形复用与完整值、缩放、比较曲线、分页/轴方向、旧/新格式、子窗口/锁定复制和保存恢复。
- 桌面 `matching-analysis.wkb` 隔离副本的 DP+EW 验收通过：Correlation 为 7 个相关拟合，Trend 为 4 个相关面板（保留原文件中的比较设置）；均与两次单选结果的并集一致。
- 多选保存重开通过，原始 Raw / Reference 和子窗口原始表精确比对通过；原桌面 WKB 与正式设置 SHA256 未变。
