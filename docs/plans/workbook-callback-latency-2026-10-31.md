# Workbook GUI 回调耗时优化（2026-10-31）

**结论：实现与正确性验证完成，100 ms 性能验收未全面通过。** 不将局部回调缩短表述为整次刷新达标。

基线为 `v4.3.6`，保留此前主窗口 Raw Data 临时清空时 Correlation 不清空的本地修复。未修改回归、插值、单位、色阶及导出计算规则。

## 改动

- 自动刷新先发布分析结果，再分批更新参数图与单 Wafer 指标；显式 Run 和首次结构创建保留同步路径。排队工作检查源版本，关闭及后续编辑取消旧工作。
- 在后台准备参与记录、Map 阶段数据和不可变表版本；GUI 复用已验证的来源，减少重复转换、复制与分组准备。
- 分组计划只在来源身份、相关字段与设置未变化且无筛选/排序时复用；分析标签缓存按结果和显示选项隔离，数值重新拟合。
- 数值编辑复用单 Wafer 指标与可安全更新的明细图；缺失值恢复保持散点和 Die 悬浮信息对齐。
- 主图分批更新结束后才准备子窗口数据，子窗口提交结束后再启动其绘图后台任务。保留手动输入和未保存草稿保护。

## 正确性与回归

- Map 数据/曲面/RGBA/几何标签的内容哈希在前后相同；父子窗口源字符串与行序断言通过。
- 真实 NOVA 7,731×33、3 参数：拟合汇总、逐行数据、单 Wafer 拟合与独立全新计算完全一致；8 种标签选项一致，修改 Wafer 身份后正确重算。串行验收起止检查中，原始 WKB 与真实 settings.yaml 哈希一致。
- 后续终检发现 settings.yaml 的哈希又发生变化，来源未判定；保留当前文件，没有回写覆盖。因此不声称该文件在整个对话内始终不变。生产源码哈希与最终验收记录一致。
- 全量 `python run_tests.py`：1272 项，3 失败、2 错误，864.806 秒；不是全绿。
- 4 项 OCR 失败/错误来自缺少 cv2 的原有环境问题。另一次 Map 打开耗时 429.8 ms，超过 400 ms 门槛；原标签 3 次专项也出现一次 419.7 ms 超限。当前代码 3 次专项重跑均通过（首次打开约 193–199 ms）。
