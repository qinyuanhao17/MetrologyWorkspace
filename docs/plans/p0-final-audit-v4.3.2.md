## 已复现并修复的局部问题

1. **主窗口 Data Selection 排除完整 wafer 后，Map/Radius 没有恢复绘制。**
   参与行其实已同步，但网格变化使页面失效，源表未变的快捷返回跳过了绘图恢复。
   `_refresh_stage_workspace` 只恢复此前成功且没有 pending Draw 的**精确存活**选项，
   不换成另一 wafer，不替换独立源表。补测保存/重开分组 WKB，以及源表和成员同时改变
   时只恢复一次。单行排除/子窗口本地选择原本正常，没有被误改成全软件强制复制。
2. **慢 Correlation 恢复时，自动刷新计时器与显式恢复重复绘图。**
   `MainWindow.input_update` 在最终计划发布后、第一张显式恢复前，停止本次待恢复页的
   自动计时器；保留全部显式绘图与新输入的后续刷新。红回归观察到重复 fit，修复后
   真实 Qt timeout 不再发生，最终 Trend 中有更新后的 `CD=1.1`。没有改 Undo、
   frame 所有权、分析算法、revision/generation 或异步结果协议。
3. **普通 Excel 轴被 `numRef` 误判。** `set_categories()` 的普通 RSQ/Dynamic 图
   本来也使用 numRef；此前 X 轴被隐藏而没有替代绘图。现在仅明确 identity 元数据可
   隐藏轴。`write_all_trend_sheet` 是未调用的旧 helper，不宣称实际导出了 All Trend。
4. **末尾 Die tick 绕过防碰撞。** 移除最后一项无条件放行，只采纳满足实测间距的
   标签；不移动、删减或插值数据点，不改源 Die 文本和链接。
5. **Dynamic 菜单。** 移除 Workbook selection / Full data 两个菜单项，保留本地
   Data Selection、已有输入及旧 WKB 保存字段。未扩大为持久化语义迁移。
6. 修正 feature 中“软件拟合固定不重算”“仍导出逐 Die Cycle Trend”的过时说明。

每项的 red/green 日志、原生文件和哈希均列于机器 JSON。开发中曾用实例 mock 漏看
已经绑定的 Qt slot，后改为实际 timeout 观察；曾错误期待旧 All Trend helper 输出，
查明当前规格不输出后撤掉这一无效新假设，没有新增未请求 sheet 或放宽旧测试。
Map 的双恢复只确认重复失效/状态恢复，不冒称已经证实两次实际渲染。
