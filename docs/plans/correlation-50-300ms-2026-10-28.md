## 已取得的证据

纯拟合同输入 3 轮：原 lmfit P50 3912.29ms；闭式 OLS 初版 451.21ms；
拥有且只读的数值向量复用 377.71ms；同一次批量请求内统计量复用 295.16ms。
这些只代表纯拟合，不能称为全链路 300ms。
小样本（少于 128 点）、单对公开接口及数值病态条件保留原 lmfit 路径。
噪声/量级/NaN/异常值与未修改的单对 lmfit 对照；旧精确断言保留。

## 下一步最小范围

先做同结构、无锁定普通 SheetModel 的矩形数值粘贴；保持原 CellEdit 供一般编辑回退。
候选内部表示为命令独占的逐列旧/新原字符串向量和行区间，避免为 500,000 格重复
构造及遍历多份坐标字典。一次 Ctrl+V 仍为一次 Undo，dataChanged/changed 回调当场
必须读取一致的新数据，Undo/Redo 回到相同字符串、行身份、参与状态及合法显示范围。
不可把 Python 命令回调提前返回当成数据或图形就绪。

严格前置条件：同表头、同尺寸、非投影、普通模型、行身份及非空性不变；结构/空白/
元数据锁/自定义模型/合并字段/未知通知均走旧路径。不修改 WKB/Recovery 格式。
CellEdit/PasteReport 的既有只读映射行为须保留；不通过按需延后回执统计掩盖 UI 卡顿。
文件保存、后台快照及独立草稿不允许观察半提交状态，也不共享新增可变存储。

对子表利用既有 generation、Copy from WKB 与独立草稿检查，验证结构和源行身份不变
后，只提交本次变更列，复用识别和选择器元数据。所有分析帧/数值结果仍更新；任何
不确定性完整回退，不用版本号猜测取代必要的草稿精确比较。

绘图仅在上述数据改动验证稳定后处理：保持所有点、尺寸/颜色/缺口/拟合/轴范围及导出，
复用已有面板布局，研究统一点样式的重复准备。不得减少样本或只刷新聚焦窗口。
