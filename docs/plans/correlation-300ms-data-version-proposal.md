# Correlation 300ms：下一阶段数据版本方案（未实施）

2026-10-28。当前批量事务方案已获批准并已实施；本文件提出更深的一层改动，尚未获批。
不修改 WKB/Recovery 文件格式，不开始目录重构，不推送或发布。

## 用直白的话说

目前一次粘贴要让表格、Workbook 分析、子表、相关计算分别准备自己的完整数据。
已完成的优化减少了其中的逐格记账和图布局重建，但仍要重复搬运、比较很多数据。

下一步建议让一次改动只生成一个**不可变数据版本**。各分析读取这个版本；再次编辑
生成新版本。需要独立编辑的子窗口获得自己的版本，继续保留草稿归属与精确基线检查。
图仍随数据刷新，不依赖焦点或当前 Tab。完成时间仍包括数据、拟合和当前图的更新。

## 为什么需要单独提出

现有 10k 行、50 参数表格层粘贴中位数仍约 765ms，单这一层已经超过总预算。
50 参数完整刷新单次测量仍约 V=4.15s、Z=3.13s；只改一列并停在 Data Tab 约
V=2.47s、Z=2.10s。这些是当前实际断点，不是本方案的性能承诺。

本阶段新增范围会改变 `SheetModel.cells` 的内部存储和主/子窗口读取数据的归属。
它超出已批准的“命令按列记账、严格回退子表增量提交”。用户此前明确要求数据所有权、
Undo 事务及异步发布等高风险修改先提供方案与风险，所以不能直接扩大实施范围。

## 分步边界

1. 先新增可独立测试的列式表数据版本。源字符串、表头、记录行标记与位置全部保留。
   不把字符串强制变成浮点。已有 `cells` 的读写、copy、快照、普通 Undo 和投影接口
   保持兼容；未知/直接 mutation 必须使快路径失效，不能只依赖 revision 猜测。
2. 只替换严格同结构批量数值路径。新列由新版本独占；未变列只能共享不可变存储。
   DataFrame 公共读取仍返回可独立修改的副本；内部分析通过明确只读入口读取。
   一次编辑仍是一次 Undo，所有必要通知与回调即时读数保留。
3. 父/子使用同一来源版本准备分析，减少同一事务的重复完整复制、识别和比较。
   独立草稿、手动 Ref、Card、Group、Mapping、参与选择与基线接受仍沿用原语义。
   结构、空白、身份、锁定及未知上下文全部保留原路径。
4. Correlation 在上下文与原行配对被证明不变时复用未受影响的参数对；全部参数变化
   时研究共同有效行上的批量矩阵 OLS。缺失值/病态输入继续原安全回退，保留现有
   数值误差检查、坐标方向、颜色、单位、拟合排序和过滤规则。
5. 只有数据阶段证明有效后，再处理散点的重复样式准备。所有原始点和绘图风格保留，
   不抽样、不移除点、不通过把图片等到聚焦时才更新换取计时成绩。

每一步单独 profiling、红回归、最小改动、专项回归、相同输入前后对照；不能同时
替换模型、Undo、发布机制和渲染器。某一步没有收益就不保留其额外复杂度。

## 必须锁住的风险

- 源字符串与精度、重复/前导零标签、空白记录、原行映射和参与状态不能改变。
- 旧版本和旧公共快照不可随新编辑改变；不共享新增可变帧或数组。
- 普通编辑与批量编辑交错、快速 V/Z/Y、嵌套回调和未知 changed.emit 都必须正确。
- 保存/Recovery/导出只接受完整且当前的版本，不得捕获半提交状态。
- 旧后台结果、取消、关闭、重新打开与人工子表编辑必须继续拒绝错误覆盖。
- 只允许有界的计算缓存；不减少 Undo 历史，不用 RSS 波动直接判泄漏。

## 验收、停止与回滚

固定保留 10k 行 ×50 个已绘制参数、全部 100 wafers、1225 个参数对的密集更新；
另测只改一列、非聚焦 Raw 浮窗和 Data Tab 场景。不能用后者替代前者。
记录冷/热、完整耗时、按键阻塞、Qt 停顿、全部断言与重复样本；300ms 门槛不变。
首次导入、结构变化和 100k×33 分开记录，不伪装为正常热更新的成功。

沿用既有框架，先专项、源码稳定后一次完整隔离回归；原设置/原 WKB 哈希保护。
每个有效步骤保存独立本地 checkpoint，回滚只撤销本步骤源/测试，不 reset 用户工作。
若达不到 300ms，报告剩余热点和真实数据，不提前宣布成功。
本方案没有未经测量的耗时保证。完成本阶段后停止，不自动进入 P1/P2/P3 或发布。
