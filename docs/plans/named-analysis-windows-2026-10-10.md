# 命名分析窗口与持久化

用户已确认：名称、勾选状态、独立数据和绘图设置随 WKB 保存。

## 交互合同

- 三种工具的入口为原生分区按钮。左侧打开或唤起该阶段所有勾选窗口；右侧下拉提供新建和复选列表，双击窗口条目直接重命名。
- 窗口复选列表单击勾选后保持展开，以便完整双击能被识别；双击和取消改名均保留原勾选状态。键盘 F2 可重命名当前条目。
- 新建输入名称；同工具同阶段名称唯一，忽略大小写和首尾空格。取消不新增任何状态。
- 窗口关闭后仍保留名称；下次勾选并点击左侧可重开。已有窗口仅激活，不用 Workbook 覆盖草稿。
- Preview / Final 名单分开；窗口标识使用 UUID，不依赖可编辑的名称。
- 左侧在旧 WKB 尚无名单时保持原来的默认窗口入口，旧保存数据继续可读。
- 全部取消勾选时左侧不打开窗口，不擅自新增默认窗口。

## 保存和恢复

- 每个窗口拥有独立的源表、选择和分析 UI 保存位置；未编辑的关联数据仍跟随 Workbook，不冻结无关源表。
- Workbook Save 接受所有当前草稿；子窗口 Save 只接受本窗口草稿，其他窗口保留各自未保存状态。
- Cancel / Discard、Save As、recovery 保留既有保护。恢复后即使没有先打开子窗口再保存，也保留每个独立草稿。
- Workbook 统一 Cards 和 Analysis 全局设置保持既有含义，不改变数值或原始表。
- 修复了独立 Correlation 重开时混入临时 Workbook 分组的问题；参与排除集合使用稳定排序序列化。

## 流畅度修复

真实 7,731 × 33 的 `testfilter1`，反向源行投影，独立进程 30 次实际 Ctrl+A。

| 中位数 | 299.5 ms | 6.8 ms |

表中为注册实际 Windows 字体后的独立进程复测；首次未注册字体的测量结果相近（中位 298.7 → 6.3 ms）。

归因：每次约 25.5 万次 Mapping 值访问重复从显示行映射回源行，且反复全表扫描。
修复只一次遍历源单元格，在源 revision / 显示行变化时失效边界缓存；不改值、锁、撤销、隐藏行和内部空白选择语义。
剪贴板与筛选大表原性能门槛测试 22 项通过，新增覆盖编辑、Undo、表头变化、筛选/排序及空投影。
这些数字为离屏 Qt 回调加绘制事件处理耗时，不是显示器帧率，不表示所有操作都提高相同比例。
