`5.1.0`, a Windows x64 per-user Setup and a portable ZIP. Synchronize remote
CXMT by fast-forward to the release commit, preserving main and historical

are excluded from the commit and artifacts.

selection rings and Test Flag glyphs. A real 20-SME fixture verified all five
render settings and a rendered card with blue/gray points, selected ring,
green/red flags and readable labels. Marker positions, flags and selection
semantics are unchanged.

README, root HANDOFF, docs/HANDOFF and the executable scenario map now describe
the current Spectra workflows and test scope. Old no-WKB/export and checked-only
Die Map descriptions were removed. The Inno recipe accepts explicit application
and numeric file versions and generates its output name from the release
version rather than retaining dev1 metadata.

## Packaging and release verification

Package only an isolated Git archive of the exact annotated release tag.
Release builds include VERSION and BUILD-INFO, the Conda `sqlite3.dll` and PE
file/product version 5.1.0.0 / 5.1.0. PyInstaller and Inno Setup remain the
existing build tools. Setup wraps the same files as the portable ZIP.

The publication workflow requires these checks before making the draft public:

1. Reject personal workbooks, SME, spreadsheets and settings in the payload;
   record each shipped file's SHA-256.
2. Run the frozen Spectra smoke with Python/Conda/PYTHONPATH removed from PATH,
   real SME sources and scratch settings. Verify native rectangle selection,
   double-click participation and no AutoWeighting import.
3. Check ZIP CRC, extract into a fresh owned directory, compare every payload
   SHA-256 and rerun the frozen smoke.
4. Install/reinstall/uninstall in an owned scratch directory with
   `/NOINTEGRATION=1`. Verify identical shipped hashes, preserved user-data
   sentinels and unchanged existing installation registration.
5. Verify remote annotated tag's peeled commit, CXMT head, main's original
   `aa5281dd38bbe58688a51b27e86c70635aef7a77` and uploaded asset sizes/digests.

Exact build, install and remote-publication results are recorded with the
artifacts in `BUILD-INFO.json`, `BUILD-VALIDATION.json`, `PAYLOAD-SHA256.json` and
`CHECKSUMS.txt`. These artifact results follow the fixed source commit; this
source document describes the required checks rather than pre-claiming that
unfinished packaging has passed.

Performance and numerical-equivalence evidence for the supplied 1,890-spectrum
Workbook remains in [the storage/performance report](spectra-performance-storage-2026-11-03.md).
No additional universal performance guarantee is made by this release.
