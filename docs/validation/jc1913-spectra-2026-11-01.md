## Changes and causes

- Recognize the encryption signature before reading the whole payload. Report `encrypted`, the source directory, the full path in the tooltip, and the need for a decrypted SME copy from an authorized environment. Other readable files remain available. Repeated Add does not duplicate identical issues.
- Reuse one resolved path and file stat per readable file instead of repeating filesystem work. Throttle worker-to-GUI progress messages to approximately 50 ms while preserving the first and final updates.
- Reserve footer height and ignore the status label's horizontal size hint. Showing progress/Cancel or a long filename no longer resizes every dense plot and triggers whole-grid repaints.
- Retain unchanged plot items and their ranges. Native Qt `DeviceCoordinateCache` avoids painting the same dense lines again on ordinary repaints; the shared pixmap cache is bounded at a minimum of 64 MiB. Data or transform changes regenerate the affected rendering.
- Prepare large plot changes once, then paint one chart per event-loop turn with Drawing progress. Selection highlights are batched by channel, excluded from auto-range bounds, and use the existing 5 px solid pens. Source samples, NaN gaps, curve identity, and viewport clipping remain intact; no averaging or resampling was added.
