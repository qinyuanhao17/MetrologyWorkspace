# v5-dev1 Windows release validation

The Die Map name and native rectangle selection are retained from v5-dev.
The new source/frozen `--spectra-smoke-test <SME-folder> <report.json>` command
exercises real SME loading, the Die Map title, rectangle selection and native
double-click checking. It records whether AutoWeighting was imported and
never runs that module's self-test or OCR inference. The source-entrypoint,
Die Map and installer-wrapper focused run passed 13 tests before packaging.

The existing full scoped v5-dev baseline ran 1,354 tests, with three known
unrelated Correlation/literal-frame failures. The v5-dev1 source extraction is
run through `python run_tests.py` again, retaining the explicit AutoWeighting
exclusions and isolated settings. Exact final counts belong to the release's
build-validation asset, rather than being inferred from the baseline.

## Reproducible artifact checks

Build from an isolated Git archive of the release source commit. Include
VERSION, BUILD-INFO and the Conda SQLite DLL in the portable payload. Produce
Setup from that same payload, then compare installed files with the payload
manifest. Test the executable with Python/Conda/PYTHONPATH removed from PATH,
using scratch settings and real SME fixtures. Test the ZIP after extraction.

The Inno Setup test flag `/NOINTEGRATION=1` skips both shortcuts and the
Add/Remove Programs registration; normal installation retains them. Install,
reinstall and uninstall tests use an owned scratch directory and verify that
personal settings, `.mwkb` and `.spec` sentinels survive. No running user
installation is overwritten for validation.

The published development Release supplies Setup, portable ZIP, SHA-256
checksums and build/validation provenance. It remains a prerelease and does
not move historical tags or publish local workbooks, SME data or settings.
