# 欢迎使用 Help

这里是 Metrology Workspace 的 SOP / 使用教程入口。

左侧按模块组织教程。[Summarize REF](summarize_ref.md) 和 [Correlation and Trend](correlation_trend.md) 已提供操作流程、注意事项和界面示例；其余占位章节将逐步补充。

## 阅读帮助

- 点击左侧章节查看内容，展开箭头查看子章节。
- **Filter topic titles…** 按标题过滤目录。
- **Back / Forward** 在已浏览的页面间切换，**Home** 返回本页。
- **Refresh** 或 **F5** 重新读取手动修改的目录和正文。
- **Open help folder** 打开文档文件夹。

## 添加教程

修改 `pages/` 内的 Markdown 正文，并在 `toc.yaml` 中维护章节层级。
